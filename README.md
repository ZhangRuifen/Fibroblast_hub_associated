# Fibroblast–Macrophage Interaction Project
This repository focuses on systematically characterizing the interactions between fibroblast subpopulations and macrophages at single-cell resolution, with an emphasis on ligand–receptor communication, temporal dynamics, and perturbation-aware interpretation.
The project integrates single-cell RNA sequencing data, cell–cell communication inference, and trajectory-aware analyses to dissect how fibroblasts influence macrophage states during disease progression or tissue remodeling.
